# 1.2.2使用说明

日期：2026-11-06。本节为当前版本；后面的原来版本内容仅供追溯。

## 两块板的分工与接线

| 核心板模块 | 接线/参数 |
| --- | --- |
| 肌电 | 模拟S=GPIO34（ADC1），佩戴L=GPIO2 |
| 肌电三级LED | GPIO5/18/19，旧包络阈值6/9/12 |
| MPU6050与128×64 SSD1306 OLED | 共用SDA21、SCL22；MPU0x68/0x69，OLED0x3C/0x3D |
| MAX98357 | BCLK26、LRC25、DIN27；喇叭接SPK+/SPK-，不接地 |
| HC-04脑电链路 | UART2：RX16、TX17，57600；TX与RX交叉、共地 |
| 预留UART1 | RX4、TX13，9600 |
| 配置重置按钮 | GPIO33接GND，内部上拉，持续约1秒清配置并重启 |
| USB调试 | 115200；端口按本机实际选择 |

不同模块电源规格需对照模块说明；ESP32 GPIO使用3.3V逻辑，执行负载通过驱动电路，不能直接挂GPIO。

执行板是另一块ESP32，使用自己的GPIO25/26/2，与核心板同号引脚互不冲突。

| 脑电条件（新的有效包） | 命令 | 执行板GPIO25 | GPIO26 | GPIO2 |
| --- | --- | --- | --- | --- |
| 专注度>70，连续两包 | on | 低 | PWM软启动后高 | 高 |
| 专注度<50，连续两包 | off | PWM软启动后高 | 低 | 低 |
| 50～70（含边界） | 保持 | 保持 | 保持 | 保持 |

目标输出以20kHz、8位PWM在约300ms内升到满占空比；切换先撤销全部输出。上电三路低；断流/失联保持最后确认输出，不自动断开负载。GPIO2是状态指示，on时立即高，GPIO26随后爬升；仅最终状态同步。软启动不是通用过流保护，具体负载和供电需实测。约300ms爬升期间接收端主循环暂不处理新命令，队列保留最新收到的快照。

## 配网与网页

首次配置热点ESP32不设密码，浏览器打开192.168.4.1，保存Wi-Fi及云端API配置后重启自动连接；断电后配置仍保存。不要把真实值写进GitHub文件。

核心板进入已配置Wi-Fi后，OLED显示设备IP。同一Wi-Fi内手机/电脑打开该IP，使用真实数据分析页面。手机热点需允许局域网互通。页面没有聊天按钮，也不采集执行板数据。

网页按钮先排队，显示“设备已执行”才是处理确认；忙态拒绝操作。OLED/扬声器开关和音量重启恢复默认。图表暂停只暂停浏览器绘图，不停止板上采样。脑电无线“提交成功”不代表执行板GPIO已经物理动作。

IMU更新失败或云端业务占用主循环时会显示原因。网页为400ms轮询/1200ms展示余量，接口仍要求真实IMU样本不超过400ms；不使用重复旧时间戳制造连贯。肌电图是包络趋势，不是500Hz原始波形。

## 演示与九键拼音

默认演示模式：自然放松等待就绪，画三角形或Z，结束后停稳，OLED显示句子并调用云端TTS。当前模型来自个人采集；换人/换佩戴方式可能需要重训。

串口发送m或用网页切换到拼音。九键组为分隔、ABC、DEF、GHI、JKL、MNO、PQRS、TUV、WXYZ。上下选组，右侧翻进入组；上下选字母，右侧翻输入并回到组选择。组内逆时针返回，组外逆时针删除；顺时针输入分隔符。只有组外且已有拼音时，握拳保持约1秒请求联想。候选上下选择、右侧确认播报、逆时针返回。

上下保持进入连续翻动时会抑制其他手腕分类及握拳联想；放回停止。不是百度输入法，云端候选仍需用户确认。云端/TTS忙时不积攒新操作，结束后自然放松再操作。

## 故障与升级

用115200串口p/e/h查看状态，不公开密钥。无声时看【语音错误】；本版已改分块PCM播放，但账号权限、网络和实体音频链路仍会影响结果。升级请选择正确板和8MB分区，不主动整片擦除；本发布动作没有烧录或清除任何设备配置。

# 接线与操作

## 接线

主控：经典 ESP32-WROOM-32E，8MB Flash、无PSRAM。

| 模块 | 接线 |
|---|---|
| MPU6050 和 OLED | SDA GPIO21，SCL GPIO22，共地；按模块规格供电，I²C逻辑使用3.3V |
| 肌电模拟信号 S | GPIO34（ADC1，可与Wi-Fi同时使用） |
| 肌电佩戴信号 L | GPIO2 |
| 肌电指示灯 | GPIO5、18、19；保留原滤波包络6/9/12三级显示 |
| MAX98357 | BCLK GPIO26，LRC/WS GPIO25，DIN GPIO27；喇叭接SPK+/SPK− |
| HC-04 UART2 | ESP32 RX GPIO16接模块TX，ESP32 TX GPIO17接模块RX，57600 |
| 预留 UART1 | ESP32 RX GPIO4、TX GPIO13，9600，默认不启用每秒发送测试 |
| 配置重置按钮 | GPIO33接按钮，另一端GND；内部上拉，按住约1秒清配置并重启 |
| USB调试 | 115200 |

芯片输入不接受5V逻辑；具体模块电源端电压按模块规格确定。GPIO2为启动相关引脚，启动状态还需结合实物电路检查。

## 连续选择

手腕上翘／下压并保持，字母正常连翻间隔300毫秒、候选450毫秒。直接进入保持识别需沿已训练的上下轴偏转至少40度并稳定300毫秒；模型已确认上下翻且仍保持至少30度时可以接续连翻。

保持期间不再因倾角相对峰值回落10度而退出；轻微运动暂停重复，稳定120毫秒后按正常重复间隔接续。回到24度以内、方向反转、明显转动、轴向不符或数据中断仍会停止。参数是当前工程值，不代表所有佩戴条件下的最优值。

自然位参考建立后，请保持MPU固定安装方向。画圈和右侧翻仍走原200帧模型窗口，不能把连续选择的较短启动时间理解为所有动作的延迟。

## 串口排查

`p`查看版本、采样状态、佩戴、肌电值、姿态阶段和栈余量；`t`切换诊断；`c`重新记录自然位。软件操作键w/s/f/b/空格/x分别为上下选择、分隔、回退、确认和联想。

联想报错先记录HTTP状态与服务错误码。429可能有不同服务侧原因，不应单凭状态码判断余额或调用过快。旧qwen-turbo下线事件见更新记录。
