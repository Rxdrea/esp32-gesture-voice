# 验证范围与限制

## 本次更新 2026-10-14

## 离线验证工具

运行 `python tests/run_all_tests.py` 使用真实业务源码与本地硬件/HTTP替身，无串口或真实云请求。需C++17编译器和ArduinoJson。环境变量CXX指定g++绝对路径，ARDUINOJSON_INCLUDE指定ArduinoJson/src。

未配置GESTURE_TEST_DATA时只执行不依赖私人CSV的场景，并明确跳过数据回放；配置该变量后指向补录数据根目录，每类子目录包含对应008至010.csv，额外回放up/down/clockwise/counterclockwise/right_side/grip/rest验证记录。001至007为训练，008至010为验证。仓库不含这些私人CSV。

本次同步将已有“角度回落即停止”的旧断言改为“仍保持35度则接续，真正回位停止”，以对应容错方案；该断言修改后尚未运行。旧核心测试及其运行脚本已从当前目录移除；原来版本测试可从Git历史获取。

- 换佩戴位置、用户、动作速度和电极状态可能影响识别，需继续实物验证。
- 画圈／右侧翻仍使用200帧窗口，暂无统一低延迟保证。
- 云端模型是否授权、额度和候选内容质量需真实账号验证。
- HTTPS现沿用setInsecure，尚未实现证书校验；设备配置热点无密码，适合受控调试环境。
